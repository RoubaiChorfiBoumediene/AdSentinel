Page de démonstration AdSentinel

Cette page simule une publicité qui reproduit, sans aucun code malveillant, les comportements du SDK décrit par Confiant : empreinte de l'appareil, surveillance du comportement, vol de cookies, DNS chiffré, canal C2 et exécution de code dynamique.

Toutes les requêtes visent des domaines en .invalid (qui n'existent pas) ou une adresse IP réservée à la documentation : aucune donnée ne quitte ta machine.

Ouvre ensuite le popup AdSentinel : le badge doit afficher plusieurs alertes, dont une critique.
